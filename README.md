## Introduction

This repository is designed to support your learning journey through SEM V of CSE. Here, you will find lecture notes, reference books, practicals, and more for all your semester courses.

## Courses Covered:
  - PCC-CS501 Information Security
  - PCC-CS502 System Programming
  - PCC-CS503 Object-Oriented Modeling & Design
  - PCC-CS504 Computer Algorithms
  - OEC-CS505 Computer Graphics & Multimedia or OEC-CS506 Internet of Things
  - PCC-CS507 Java Programming
  - HM-CS508 Business English

## Resource Structure: 
  - The repository is organized by course, with each course having its own directory. Inside each directory, resources such as these can be found:
    - Lecture Notes: Comprehensive notes and slides from lectures.
    - Reference Books: Recommended textbooks and additional reading materials.
    - Practicals: Step-by-step guides and tutorials for practical understanding.


## How to Use

1. **Clone the Repository**:
   ```sh
   git clone https://github.com/kateshweta/SEM-V.git
   ```

2. **Navigate to Subject Directory**:
   ```sh
   cd SEM-V/<Subject-Name>
   ```

3. **Access Resources**: Browse and use the resources as needed.

4. **Stay Updated**:
   ```sh
   git pull 
   ```
